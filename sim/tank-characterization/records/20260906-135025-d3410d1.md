# Record 20260906-135025-d3410d1

- **Experiment**: tank-characterization
- **Claim**: the L / Q / SRF behaviour of the passive devices an LC tank
  on this PDK would be built from, measured over a deliberately wide
  candidate band (1e8 Hz .. 3e11 Hz) rather than at one assumed
  centre frequency, because the target band is not chosen yet
  (`spec/target-spec.md` row 1). This record ratifies NO spec row.
- **Devices measured**: `cap_cmim` and `cap_rfcmim` from
  `capacitors_mod.lib`, three square geometries each (20, 35, 50 um).
- **Device NOT measured**: the SG13G2 spiral inductor. IHP-Open-PDK
  v0.3.0 ships no ngspice-simulatable inductor model, so the L half of
  the tank could not be characterized in this flow at all. The probe was
  run anyway and its failure recorded -- see
  `records/20260906-135025-d3410d1-inductor.csv`, the raw log at
  `corners/20260906-135025-d3410d1/inductor_probe.log`, and README.md
  "The inductor gap".
- **Method**: 1 A AC current injection into each device's hot node, so
  V(node) = Z(f). Then Ceff = Im(1/Z)/(2*pi*f), Q = |Im(1/Z)|/Re(1/Z),
  and SRF = the frequency at which Im(Z) crosses zero. Scalars come from
  a 500 point/decade pass; the committed curves are a
  50 point/decade pass over the same range.
- **Method validation**: every corner also carries an ideal R-L-C
  reference network whose Leff, Q and SRF are known in closed form. The
  same extraction arithmetic is applied to it and compared against the
  algebra to 0.1 %; results in
  `records/20260906-135025-d3410d1-method-check.csv`.
- **PDK**: `ihp-sg13g2` at `/Users/rwalters/share/pdk` -- pinned release in
  `sim/pdk.json` (IHP-Open-PDK v0.3.0). Loaded model libraries, by
  content digest, so a reader can confirm their install matches:
  - `cornerCAP.lib` sha256 `4fc4a0f17ca2aef66ca38c2d2e7cead3307b69508d304ed073129565ec1c3e56`
