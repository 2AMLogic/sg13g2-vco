# Record 20260926-071150-7a02483

- **Experiment**: phase-noise (method check)
- **Claim**: that the phase-noise estimator this experiment grades
  `spec/target-spec.md` row 4 through -- `sim/lib.sh`'s
  `pn_crossings` / `pn_isf_steps` / `pn_gamma_stats` / `pn_l_dbc`,
  i.e. an impulse-response measurement of the ISF reduced through the
  Hajimiri-Lee kernel -- recovers the right answer on oscillators whose
  ISF and whose phase noise are known in closed form. **Ratifies no
  `spec/target-spec.md` row and says nothing about `design/vco.sch`.**
- **Method**: two synthetic limit-cycle LC oscillators
  (`testbench/tb_isf_known_answer.spice.tmpl`: L = 1e-9 H,
  C = 1e-12 F, f0 = 5.0329212104e+09 Hz, limit-cycle amplitude 1.0 V set
  by a cubic negative-conductance element) and a bare R||C port
  (`testbench/tb_portnoise_known_answer.spice.tmpl`).
  - A train of 12 triangular charge impulses of 1e-14 C
    (half-width 2e-12 s) is injected into the tank at a spacing
    deliberately offset from an integer number of periods, so the
    impulses walk the carrier phase and one run samples the whole ISF.
  - The reference run is the SAME deck with the impulse amplitude set
    to zero, so both runs carry an identical PWL breakpoint set and the
    pre-impulse crossing-offset residual is an exact null test. It is
    checked as `null_floor`.
  - Each impulse's excess-phase step is read off the plateau over the
    last 0.3 of the inter-impulse interval, so the
    amplitude transient is excluded by construction.
  - transient `tran 0.5p <case tstop>`, timestep ceiling
    `0.5p`, `uic` from the limit-cycle amplitude.
- **Closed forms checked**:
  - `Gq(phi) = cos(phi)/(C*A)`, from the phase-plane geometry of an
    LC resonator (derivation in the testbench header). Checked at every
    sampled phase, ABSOLUTELY against the ISF peak `1/q_max`, so the
    two phases where the ISF is exactly zero are a real falsification
    case rather than a vacuous relative test.
  - `Gq_rms = 1/(sqrt(2)*C*A)`, the scalar the kernel consumes.
  - `inoise_spectrum = sqrt(4kT/R)`, exactly, frequency-independent.
  - `L(df) = kTG/(C^2 A^2 dw^2)` -- Leeson's linear-tank kernel,
    derived independently of the ISF formalism, against the measured
    ISF and the measured port noise pushed through `pn_l_dbc`.
- **Tolerances**: DERIVED, not chosen. Each is the sum of closed-form
  bounds on named error terms times a stated x1.5 headroom, and each
  row's `tol_basis` column names its terms: `eps = (Gn-G)/(w0 C)`
  (the closed form is exact only as eps -> 0), `interp` (linear
  crossing interpolation relative to the step being measured),
  `2nd` (`dq/2q_max`, the second-order phase response), `width`
  (a triangular impulse is not a delta). Measured: isf_highq eps=1.897367e-02; isf_fastamp eps=1.264911e-01; 
- **Result**: 42/42 checked quantities within their
  derived tolerance.
- **End-to-end kernel check (KA-4)**: measured Gq_rms
  7.07442228e+11 rad/C and measured S_i 1.65760733e-24 A^2/Hz give
  **-139.7853 dBc/Hz** at 1e6 Hz against the closed-form
  Leeson kernel **-139.7905 dBc/Hz** (tolerance 0.4206 dB).
  `pn_l_dbc`'s Hajimiri-Lee-paper-form output for the same inputs is
  -142.7956 dBc/Hz, exactly 3 dB lower; the agreement above is what
  settles which of the two forms this repo quotes. See `pn_l_dbc`'s
  header and `README.md`.
- **Measured ISF harmonics (isf_highq)**: c0 1.05400864e+09,
  c1 1.00235056e+12, c2 7.57489968e+09, c3 6.36159633e+09 rad/C; phase grid
  12 samples, largest gap 0.632601 rad. Sample-mean
  Gq_rms 7.12322499e+11 vs trapezoidal 7.07442228e+11 rad/C -- the
  difference is what the phase grid's non-uniformity was worth.
- **PDK**: none, deliberately. The decks use only ngspice-native L/C/R
  and behavioural sources, so this check runs on a bare checkout and a
  failing estimator cannot be confused with a PDK or OSDI problem.
