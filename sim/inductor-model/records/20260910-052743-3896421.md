  bounds the truncation error as well as the netlist's correctness.
- **Method**: 1 A AC current injection into `la` with `lb` and `sub`
  grounded, so V(la) = Z(f). Then Leff = Im(Z)/(2*pi*f),
  Q = Im(Z)/Re(Z), and SRF = the f at which Im(Z) crosses zero falling.
  Scalars from a 500 point/decade pass over 1e8..3e11 Hz;
  committed curves from a 50 point/decade pass.
- **Q bracket**: every row also carries `qlow_*`, the Q that follows if
  the one-sided effective-conduction-depth assumption is used for the
  series resistance instead of the exact two-sided solution. The
  difference is this model's unmodelled lateral current crowding, and
  the true Q is expected between the two columns.
- **Corners run**: process {typ rlo rhi slo shi rlo_slo rlo_shi rhi_slo rhi_shi } x
  temperature {-40 27 125} C = 27 simulation points, each
  covering 3 geometries = 81 device rows.
  The process axes are RSTM2 (TopMetal2 sheet resistance) and RSBLK
  (substrate resistivity), swept independently; `rlo`/`rhi` and
  `slo`/`shi` are their min/max from the SG13G2 Process Specification.
  Bias is not an axis: the model contains no junction.
