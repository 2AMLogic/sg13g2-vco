# Anchor-1 yield summary-line correction — σ_f0 (mismatch) is ≈ 3.6 MHz, not the Vctrl = 0 endpoint spread (issue #367)

Append-only; supersedes one prose claim of record
`20261115-190000-0b056b1-yield-anchor1-run.md`, which is left byte-identical
(a correction is a new, superseding record, never an edit — the #88 gate's
rule, matching DR-003's). No simulation was run for this record: it is a read
of committed evidence, made because that record's summary line mislabels the
quantity it names.

## The defect, stated precisely

The anchor-1 record's AC-4 reading (its lines 155–157) says the re-tune
margin arithmetic in DR-006 can cite "σ_f0 ≈ 8.5 MHz process, ≈ 4 MHz
mismatch". The 8.5 MHz process figure is the band-centre quantity the
sentence names (`f0_bandcentre_hz`) and is correct. The ≈ 4 MHz mismatch
figure is **not** that quantity: it is the mismatch instrument's
**Vctrl = 0 endpoint** σ (≈ 4.06 MHz), from the per-endpoint table of the
same record (line 94: f(0 V) σ ≈ 4.06 MHz, f(3.3 V) σ ≈ 3.12 MHz, computed
from the paired endpoints in `evidence-s1-mismatch/report.json`). The
sentence names the band-centre σ_f0; the number it carries is a single
endpoint's spread.

The corrected summary sentence reads: the spread around the miss is measured
at **σ_f0 ≈ 8.5 MHz process, ≈ 3.6 MHz mismatch**, and DR-006's re-tune
margin arithmetic cites that band-centre pair. The endpoint spreads
(4.06 / 3.12 MHz) remain the right figures for endpoint-specific questions
and stay in the per-endpoint table, which this correction does not touch.

- Nothing was re-measured, re-fit or interpolated. Every number above is read
  directly from a committed file: the two envelopes' `distribution.stddev`
  (each n = 400, normal fit, confidence 0.95, `target_ci_halfwidth` 0.01)
  and the anchor-1 record's own per-endpoint table. The envelopes' sampling
  limits apply to these values unchanged.
- In the same change, the yield plan's precondition table
  (`../yield/README.md`, row P5) is corrected in place from "4.0 MHz
  mismatch" to "3.6 MHz mismatch" so the plan and the record agree. That

  an in-place edit is permitted there (`check-sim-append-only.sh` scopes the
  append-only rule to those directories below `sim/`).
- `sim/record-currency.json` is regenerated by this change solely to
  enumerate this record (39 entries, was 38); it digests no record markdown

- Scope: the repo-wide search for the mislabelled quantity (`σ_f0` /
